# ALD Conformality — Inverse Problem via Amortized Inference

고AR 구조의 **step coverage 프로파일 한 장**에서 표면반응 파라미터(sticking coefficient 등)를
불확실성과 함께 역추정하는 신경망. 측정마다 반복되는 시뮬레이션 최적화 루프를 학습된 추론기로 대체한다.

목적: ASM (Senior Engineer II, Product Intelligence) 면접용 포트폴리오.
부수 타깃: SK하이닉스 소자/TCAD (kMC · Physics AI), LG Display VDE (약함).

## 1. 문제

- ALD를 고AR trench/via에 하면 입구는 두껍고 바닥은 얇다 (step coverage).
- 알고 싶은 것: **sticking coefficient s₀, 입체 인자 n, 재방출 계수, 열분해율, 사이트 밀도**.
  이 값이 정해지면 *다른 AR 구조에 필요한 dose* 를 예측할 수 있다 = 공정 처방.
- 순방향 모델은 **시뮬레이터뿐**이다 (닫힌 해 없음): s(θ) 의존 → 비선형·비정상,
  재방출 각분포, 열분해, 사이트 밀도 불균일이 들어가면 해석해가 사라진다.
- 따라서 기존 역추정 = 측정 1장당 무도함수 최소제곱 → 시뮬 10³~10⁴회, 수 시간~수 일,
  확률적 목적함수(gradient 없음), 다봉, **불확실성 없음**.

## 2. 접근

```
파라미터 prior + 공정조건  →  MC 시뮬레이터  →  프로파일 + 측정열화  →  20,000쌍
                                                                        ↓
                                            1D CNN + Mixture Density head 학습
                                                                        ↓
                                     측정 1장 → 순전파(ms) → 파라미터 + 사후분포
```

비용을 **측정 시점에서 학습 시점으로 이동**시키는 것이 핵심. 물리는 대체하지 않는다.

### 데이터 한 개의 형태

| 항목 | 내용 |
|---|---|
| 입력 y | 깊이 방향 커버리지 프로파일 64칸 (측정 시 10칸 마스킹 + 노이즈 ±3%) |
| 입력 c | 공정조건 — AR, dose, T (**알려진 값**) |
| 정답 p | s₀, n, 재방출 생존확률, 열분해율, 사이트밀도 (**추정 대상**) |

> 코드의 `reemit` 은 **각분포 파라미터가 아니라 재방출 생존확률**(1 = 손실 없음)이다.
> 각분포를 추정 대상으로 삼으려면 정반사 비율이나 cos^m 지수를 따로 넣어야 하며 아직 미구현.

## 3. 시뮬레이터

2D trench 탄도 몬테카를로. Knudsen(분자류) 영역 → **절대 치수 무관, AR = H/W 만 의미**.
W=1 고정, H=AR.

입자 하나: 입구 진입(cosine) → 직진 → 벽 충돌 → 확률 s(θ)=s₀(1−θ)ⁿ 로 반응(정지),
아니면 확산 재방출 → 반복. 반응하거나 입구로 탈출할 때까지.

**각분포**: 입구 진입도 재방출도 모두 안쪽 법선 기준 **cosine(Knudsen) 법칙**.
입구에서의 cosine 은 임의 가정이 아니라 평형 Maxwell 기체가 평면을 통과할 때의 정확한 각분포다.
재방출의 cosine 은 완전 열적응 + 무작위 탈리를 가정한 것으로, **여기가 모델링 선택 지점**이다
(실제 표면은 부분 정반사가 있을 수 있음).

**속도는 추적하지 않는다.** 자유분자류에서 벽 충돌 *순서* 는 속력과 무관하므로 기하 문제에는
방향만 있으면 충분하다 (Maxwell 분포에서 속력과 방향은 독립). 속력이 필요해지는 건 두 경우:
(i) dose ↔ 시간 환산 (Hertz–Knudsen flux, v̄ = √(8kT/πm)), (ii) **rate 기반 표면 이벤트를 넣는 순간**.
즉 하이브리드 kMC 로 가면 시계가 필요하고 거기서 T·질량이 들어온다.

**표면 확산은 없다.** 반응한 종은 그 칸에 영구 고정된다. ALD 화학흡착종은 결합이 강해
공정 시간 척도에서 표면 확산이 무시할 만하다는 것이 통상적 근거이고, conformality 를 지배하는 것은
흡착종의 확산이 아니라 **전구체의 재방출** 이다 (이건 모델에 있음). 다만 물리흡착 전구체가
표면을 따라 이동하다 반응하는 경로를 넣는 모델도 있으므로, 단순화 항목으로 명시할 것.

### θ 는 어떻게 계산되나 / '포화 두께' 의 정의

칸 i 에는 반응 가능한 표면기(site)가 `N_sites,i` 개 있다. 분자 하나가 그 칸에서 반응하면

    θ_i  ←  θ_i + 1 / N_sites,i          (pseudo-particle 이면 weight / N_sites,i)

즉 **θ = (그 칸에서 반응한 분자 수) / (그 칸의 사이트 수)** — 무차원, 0..1.

`N_sites,i` 는 임의 상수가 아니라 물리량에서 온다. 칸 높이 = H/64, 벽 면적(단위 폭당) = 2·H/64,
사이트 밀도 n_s [nm⁻²] → `N_sites,i = 2·n_s·H/64`. AR 을 바꾸면 칸 높이가 바뀌므로
**사이트 밀도를 고정하려면 N_sites ∝ AR 로 같이 키워야 한다** (검증 스크립트가 이렇게 한다).

**포화 두께** = 반쪽반응이 끝까지 갔을 때 그 사이클에 쌓이는 두께 = 평탄부 GPC.
이 값을 정하는 건 표면기 밀도가 아니라 보통 **리간드의 입체 크기**다:
포화 커버리지 = min(n_s, 1/A_ligand). 그래서 θ 는

    θ = 그 지점 두께 / 완전 포화 시 두께

이고, **측정에서는 TEM 단면의 두께를 웨이퍼 상부 평탄면(=완전 포화) 두께로 나누면 얻어진다.**
이 정규화가 측정 가능하다는 점이 중요하다 — 절대 단위를 알 필요가 없다.

공정조건이 들어가는 곳은 셋뿐:
- **AR** → 기하
- **dose** → 쏘는 입자 수 (dose = P·t/√(2πmkT), 압력·펄스시간은 dose 하나로 합쳐짐)
- **T** → 표면 이벤트 rate 의 Arrhenius. ← rate 기반 표면 이벤트(하이브리드 kMC)가 있어야 성립

## 4. 지금까지 확인한 것 (실측)

`src/ar_scaling.py`, `figures/ar_scaling_measured.png`

1. **무반응 투과확률**: 2D slit 은 1/AR 이 아니라 **ln(AR)/AR** 을 따름 (실측 기울기 −0.65).
   고전 자유분자류 결과와 일치 → **수송부 구현이 맞다는 증거**.
   → 표로 정리된 Clausing 인자(∝1/AR)와 대조하려면 **3D 축대칭 원통** 기하가 필요.
2. **포화 dose 의 AR 지수**는 s₀에 의존:

   | s₀ | dose ∝ AR^x 의 x |
   |---|---|
   | 0.05 | 0.39 |
   | 0.2 | 0.81 |
   | 0.6 | 1.21 |

   Gordon 의 **AR²** 는 *큰 a · 완전 포화 기준 · 수송율속* 에서의 점근이지 보편 법칙이 아니다.
   → "AR² 재현" 을 단순 코드 게이트로 쓰지 말 것. 게이트는 위 1번.
3. **AR ≲ 5 는 거의 완전 conformal** → 역추정에 쓸 정보가 거의 없다.
   학습·측정 모두 **AR 10 이상**에서.
4. **프로파일 형상은 AR·√s₀ 로 붕괴한다** (AR·s₀ 는 아님). 4-b 참조.

## 4-b. 무차원화와 정규화 (NN 학습 전 필수)

k_decomp, dose, s₀ 는 자릿수가 몇 배씩 다르다. 원시 값을 그대로 넣으면 학습이 안 된다.
두 단계로 처리한다.

**(1) 무차원군으로 묶기 — 개별 정규화보다 우선.** 프로파일을 실제로 결정하는 건 조합이다.

| 무차원군 | 의미 |
|---|---|
| **Π₁ = AR · √s₀** | 수송 대 반응 경쟁 — 프로파일 *모양* 을 지배 (아래 유도·실측) |
| Π₂ = dose / (전체 사이트 수) | 사이트당 입사 분자 수 — 포화 *진행도* |
| Π₃ = k_decomp / s₀ | 분해 대 반응 비 |
| Π₄ = n (입체 지수) | 이미 무차원 |

**Π₁ 이 왜 √s₀ 인가.** 깊이 방향 1D 반응–확산으로 보면 D_K d²C/dz² = k C 이고,
Knudsen 확산계수 D_K ∝ W·v̄ (통로 폭이 곧 평균자유행정), 단위 길이당 소모율 k ∝ s₀·v̄/W.
침투 깊이 λ = √(D_K/k) ∝ **W/√s₀**. 바닥까지 닿으려면 H ≲ λ, 즉 **AR·√s₀ ≲ O(1)**.

**실측으로 확인함** (`src/pi_collapse.py`, `figures/pi_collapse.png`):
낮은 dose(θ≪1, s≈s₀ 인 선형 영역)에서 θ(z)/θ(0) 형상을 비교하면

| 묶음 | (AR, s₀) 조합 | 바닥/입구 비 |
|---|---|---|
| AR·s₀ = 0.4 (**붕괴 안 함**) | (10, .04) / (20, .02) / (40, .01) | 0.407 / 0.259 / 0.170 |
| **AR·√s₀ = 2.0 (붕괴함)** | (10, .04) / (20, .01) / (40, .0025) | 0.407 / 0.421 / 0.448 |

즉 **Π₁ 이 같으면 정규화 프로파일 모양이 (선형 영역에서) 같다.** 남는 ~10% 드리프트는
2D 수송의 ln(AR) 보정과 유한 depletion 때문으로 보인다. 포화가 진행되면(θ→1) s(θ) 가 변해
붕괴가 느슨해지므로, Π₂ 를 함께 넣어야 완전해진다.

NN 은 Π 를 추정하고, 알려진 조건(AR, dose)으로 s₀ 등을 역산한다.
**이게 앞서 폐기한 `dose/AR²` 정규화를 대신하는, 물리적으로 정당한 버전이다.**

**(2) 남은 스케일 처리**
- 자릿수를 넘나드는 양은 **log10 변환 후 z-score**. prior 샘플링도 log-uniform 으로.
- s₀ ∈ (0,1) 이지만 수십 배 범위 → **logit 또는 log** 공간에서 다룸.
- 출력도 log 공간에서 예측하고, 물리 범위 강제(sigmoid/softplus)를 log 공간에서 건 뒤 역변환.
- 손실도 log 공간에서 — 상대오차 최소화가 물리적으로 맞는 목표다.
- 관측 y 는 이미 0..1 이라 그대로. 다만 log θ 를 두 번째 채널로 넣으면 깊은 쪽 작은 값의 정보가 산다.

**실측 소요시간** (컨테이너, 단일 코어, numba):

|---|---|---|---|

| 20 | 0.01 | 1.0e6 | 3.3 s |
| 40 | 0.002 | 2.0e6 | **14.5 s** |

**s₀ 가 작을수록 비싸다** (반응 전 벽 충돌이 많음). 평균 5초로 잡으면 20,000개 = **약 28 코어·시간**.

장시간 배치에 부적합하다.

**체크포인팅은 필수, 그리고 단순하게**:
- 결정론적 seed: `seed = hash(shard_id, i)`. 파라미터 샘플링도 같은 seed 로 → 언제든 재현

- 실행 시 **파일이 이미 있으면 건너뛴다** → 재실행이 곧 이어하기. 별도 상태 파일 불필요
- `multiprocessing.Pool.imap_unordered` 로 shard 병렬
- 원격은 `tmux` 안에서 (ssh 끊겨도 계속)
- `@njit(cache=True)` 라 재시작 시 재컴파일 없음

## 6. Physics embedding — 아키텍처에 박는 자리

| 자리 | 내용 | 판단 |
|---|---|---|
| Arrhenius 헤드 | NN이 (s₀, Ea) 출력 → s(T) 는 해석식. T 외삽이 구조적으로 물리적 | **중심.** 하이브리드 kMC 필수 |
| 출력 파라미터화 | s∈(0,1) sigmoid, 속도 softplus | 값싸고 확실 |
| Δ-learning | Gordon 근사로 초벌 추정 → NN은 잔차 | 강함, baseline 공짜 |
| 무차원군 입력 (Π₁~Π₄) | 프로파일을 지배하는 조합으로 묶어 넣기 | **복권.** `dose/AR²` 대신 이것 (4-b 참조) |

## 8. 정직성 원칙 (발표 시)

- 데이터는 **전부 시뮬레이터 합성**. 실험 검증 없음. 첫 슬라이드에 명시.
- 2D 단면, 반쪽반응 하나, 사이클 반복 선형 가정, **표면확산 없음**, 성장에 따른 기하변화 없음.
- 재방출은 완전 확산(cosine) 고정 — 정반사 성분 미구현.
- 속도 미추적 (자유분자류에서 기하에는 불필요). rate 기반 이벤트 도입 시 시계가 필요해짐.
- step coverage 로부터 sticking coefficient 를 역추출하는 것 자체는 **기존 방법**.
  기여는 "상각(amortized) + 불확실성 정량화" 로 한정할 것.
- 학습·시험이 같은 시뮬레이터에서 나온다는 자기일관성 함정 → 검증 4번이 유일한 방어.

## 9. 표기

문헌 표준(Cremers–Puurunen–Dendooven 리뷰)을 따른다.
- **s** = sticking probability (충돌당 반응 확률), **s₀** = bare surface 초기값
- γ 는 플라즈마 쪽 표면반응·재결합 확률
- β 는 통용 표기가 아니므로 쓰지 말 것

```
ald-conformality-inverse/
├── README.md          이 문서
├── docs/              설계 문서 · 워크플로우 다이어그램
├── src/               시뮬레이터 · 검증 · 그림 생성 코드
├── figures/           생성된 그림
└── results/           수치 결과 (미사용)
```

### src/
- `trench_mc.py` — 2D trench 탄도 MC 시뮬레이터 (numba, pseudo-particle weight 지원). 단독 실행 시 설명 그림 생성
- `ar_scaling.py` — 무반응 투과확률, 포화 dose vs AR 실측
- `fig_ar_scaling.py` — AR 스케일링 그림 생성
- `pi_collapse.py` — 무차원군 형상 붕괴 검정 (AR·s₀ vs AR·√s₀)

그림 텍스트는 영어, 축 라벨은 문장형 대문자 시작으로 통일한다.
