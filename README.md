# ALD Conformality — Inverse Problem via Amortized Inference

고AR 구조의 **step coverage 프로파일**에서 표면반응 파라미터(sticking coefficient, 활성화에너지 등)를
불확실성과 함께 역추정하는 신경망. 측정마다 반복되는 시뮬레이션 최적화 루프를 학습된 추론기로 대체한다.

목적: ASM (Senior Engineer II, Product Intelligence) 면접용 포트폴리오.
부수 타깃: SK하이닉스 소자/TCAD, LG Display VDE (약함).

---

## 1. 문제

- ALD를 고AR trench/via에 하면 입구는 두껍고 바닥은 얇다 (step coverage).
- 알고 싶은 것: **sticking coefficient s₀, 그 활성화에너지 Ea, 입체 인자 n, 재방출 생존확률, 사이트 밀도**.
  이 값이 정해지면 *다른 AR 구조·다른 온도에 필요한 dose* 를 예측할 수 있다 = 공정 처방.
- 순방향 모델은 **시뮬레이터뿐**이다 (닫힌 해 없음): s(θ) 의존 → 비선형·비정상,
  재방출 각분포, 사이트 밀도 불균일이 들어가면 해석해가 사라진다.
- 따라서 기존 역추정 = 측정 1세트당 무도함수 최소제곱 → 시뮬 10³~10⁴회, 수 시간~수 일,
  확률적 목적함수(gradient 없음), 다봉, **불확실성 없음**.

## 2. 접근

```
파라미터 prior + 공정조건  →  MC 시뮬레이터  →  프로파일 + 측정열화  →  ~10,000쌍
                                                                        ↓
                                            1D CNN + Mixture Density head 학습
                                                                        ↓
                                   측정 1세트 → 순전파(ms) → 파라미터 + 사후분포
```

비용을 **측정 시점에서 학습 시점으로 이동**시키는 것이 핵심. 물리는 대체하지 않는다.

### 데이터 한 개의 형태

| 항목 | 내용 |
|---|---|
| 입력 y | **온도 3점 × 깊이 64칸** 커버리지 프로파일 (3×64). 측정 시 마스킹 + 노이즈 |
| 입력 c | 공정조건 — AR, Π₂(사이트당 dose), T₁·T₂·T₃ (**알려진 값**) |
| 정답 p | s₀(T_ref), Ea, n(입체), 재방출 생존확률, 사이트밀도 (**추정 대상**) |

> **온도 1점이 아니라 3점인 이유**는 §4-e. 단일 프로파일에서는 Ea 가 원리적으로 식별 불가능하다.

> 코드의 `reemit` 은 **각분포 파라미터가 아니라 재방출 생존확률**(1 = 손실 없음)이다.
> 각분포를 추정 대상으로 삼으려면 정반사 비율이나 cos^m 지수를 따로 넣어야 하며 아직 미구현.

## 3. 시뮬레이터

**3D 축대칭 원통 via 의 탄도(자유분자류) 몬테카를로** (`src/cyl_mc.py`).
Knudsen(분자류) 영역 → **절대 치수 무관, AR = H/D 만 의미**. D=1 고정(R=0.5), H=AR.

> 2D slit 판(`src/trench_mc.py`)도 유지한다. 기하 비교 연구용이며, 두 기하의 투과확률이
> ln(AR)/AR 과 1/AR 로 갈리는 것을 보여주는 슬라이드 소재다. **학습 데이터는 원통으로만 만든다.**

입자 하나: 입구 원판 진입(cosine) → 직진 → 벽 충돌 → 확률 s(θ)=s₀(1−θ)ⁿ 로 반응(정지),
아니면 확산 재방출 → 반복. 반응하거나 입구로 탈출할 때까지.

**각분포**: 입구 진입도 재방출도 모두 안쪽 법선 기준 **cosine(Knudsen) 법칙**.
입구에서의 cosine 은 임의 가정이 아니라 평형 Maxwell 기체가 평면을 통과할 때의 정확한 각분포다.
재방출의 cosine 은 완전 열적응 + 무작위 탈리를 가정한 것으로, **여기가 모델링 선택 지점**이다
(실제 표면은 부분 정반사가 있을 수 있음).

**속도는 추적하지 않는다.** 자유분자류에서 벽 충돌 *순서* 는 속력과 무관하므로 기하 문제에는
방향만 있으면 충분하다. 속력이 필요해지는 건 (i) dose ↔ 시간 환산, (ii) rate 기반 표면 이벤트를
넣는 순간. 후자는 이번 범위에서 도입하지 않는다 (§4-e).

**표면 확산은 없다.** 반응한 종은 그 칸에 영구 고정된다. ALD 화학흡착종은 결합이 강해
공정 시간 척도에서 표면 확산이 무시할 만하다는 것이 통상적 근거이고, conformality 를 지배하는 것은
흡착종의 확산이 아니라 **전구체의 재방출** 이다 (이건 모델에 있음).

### θ 는 어떻게 계산되나 / '포화 두께' 의 정의

칸 i 에는 반응 가능한 표면기(site)가 `N_sites,i` 개 있다. 분자 하나가 그 칸에서 반응하면

    θ_i  ←  θ_i + weight / N_sites,i

즉 **θ = (그 칸에서 반응한 분자 수) / (그 칸의 사이트 수)** — 무차원, 0..1.

원통에서 칸 높이 = H/64, 벽 면적 = 2πR·H/64 = π·H/64 (D=1), 사이트 밀도 n_s →
`N_sites,i = n_s·π·H/64`. AR 을 바꾸면 칸 높이가 바뀌므로 **사이트 밀도를 고정하려면
N_sites ∝ AR 로 같이 키워야 한다** (생성기가 이렇게 한다).

**포화 두께** = 반쪽반응이 끝까지 갔을 때 그 사이클에 쌓이는 두께 = 평탄부 GPC. 그래서

    θ = 그 지점 두께 / 완전 포화 시 두께

이고, **측정에서는 TEM 단면의 두께를 웨이퍼 상부 평탄면(=완전 포화) 두께로 나누면 얻어진다.**
이 정규화가 측정 가능하다는 점이 중요하다 — 절대 단위를 알 필요가 없다.

공정조건이 들어가는 곳은 셋뿐:
- **AR** → 기하
- **dose** → 쏘는 입자 수. 무차원화하면 Π₂ = dose / 전체 사이트 수
- **T** → s₀ 의 Arrhenius 의존. 온도 3점 세트로 식별한다 (§4-e)

## 4. 지금까지 확인한 것 (실측)

### 4-1. 수송 검증 — 코드 게이트 (합격)

`src/cyl_mc.py` + `src/clausing_ref.py`, `figures/geometry_validation.png`

무반응(s₀=0) 투과확률을 **두 가지 독립적인 방법**으로 계산해 대조했다.

1. 탄도 MC (`cyl_mc.transmission`)
2. **Clausing 적분방정식의 결정론적 수치해** (`clausing_ref.py`) — MC 를 전혀 쓰지 않는다.
   원통 내벽의 링–링 교환 커널 k(u) = (R/π)∫₀^{2π} a²/D⁴ dψ 를 구적한 뒤 선형계를 푼다.
   자체 검증: k(0) = 1/(2R), ∫₀^∞ k du = 1/2 (둘 다 해석적으로 정확한 값과 일치).

| AR = H/D | MC (4×10⁶ 입자) | Clausing 수치해 | 차이 |
|---|---|---|---|
| 5 | 0.19117 ± 0.00020 | 0.19094 | +0.12 % |
| 10 | 0.10959 ± 0.00016 | 0.10932 | +0.25 % |
| 20 | 0.05942 ± 0.00012 | 0.05945 | −0.04 % |

AR 0.5~40 전 구간에서 **MC 통계오차 이내로 일치**. 짧은 관 극한에서 Clausing 의 고전값
(L/R=1 → 0.672, L/R=2 → 0.514)도 재현한다.
→ 2D slit 때의 "기울기 −0.65가 ln(AR)/AR 과 맞더라" 수준의 스케일링 확인이 아니라,
**절대값을 독립 기준과 대조하는 진짜 게이트**가 되었다. 이것이 원통을 택한 첫 번째 이유다.

2D slit 은 별개로 ln(AR)/AR 을, 원통은 4/(3·AR)(Knudsen 점근)을 따른다 — 같은 그림 (a) 패널.

### 4-2. 형상 붕괴 — Π₁ = AR·√s₀ (원통에서 더 깨끗해짐)

낮은 dose(선형 영역)에서 θ(z)/θ(0) 형상 비교:

| 묶음 | (AR, s₀) | 바닥/입구 비 | 판정 |
|---|---|---|---|
| AR·s₀ = 0.4 | (10, .04) / (20, .02) / (40, .01) | 0.056 / 0.023 / 0.004 | **붕괴 안 함** |
| **AR·√s₀ = 2.0** | (10, .04) / (20, .01) / (40, .0025) | 0.056 / 0.065 / 0.060 | **붕괴함 (±8 %)** |

2D slit 에서는 같은 시험이 0.407/0.421/0.448 (±10 % 드리프트)이었다. 원통이 더 깨끗한 것은
예상과 맞는다 — 2D 의 ln(AR) 보정항이 없기 때문이다.

**Π₁ 이 왜 √s₀ 인가.** 깊이 방향 1D 반응–확산으로 보면 D_K d²C/dz² = k C 이고,
Knudsen 확산계수 D_K ∝ W·v̄, 단위 길이당 소모율 k ∝ s₀·v̄/W.
침투 깊이 λ = √(D_K/k) ∝ **W/√s₀**. 바닥까지 닿으려면 **AR·√s₀ ≲ O(1)**.

### 4-3. 폐기된 주장

**`dose ∝ AR²` 를 코드 게이트로 쓰지 말 것.** Gordon 의 AR² 는 *큰 a · 완전 포화 기준 ·
수송율속* 점근이지 보편 법칙이 아니다. 2D slit 실측 지수: s₀=0.05→0.39, 0.2→0.81, 0.6→1.21.
게이트는 4-1 을 쓴다. (원통에서 완전 포화 기준으로 재측정하면 2 에 접근하는지는 **미확인 — 다음 할 일**.)

## 4-b. 무차원화와 정규화 (NN 학습 전 필수)

**(1) 무차원군으로 묶기**

| 무차원군 | 의미 |
|---|---|
| **Π₁ = AR · √s₀** | 수송 대 반응 경쟁 — 프로파일 *모양* 을 지배 (4-2 에서 실측 확인) |
| Π₂ = dose / (전체 사이트 수) | 사이트당 입사 분자 수 — 포화 *진행도*. 생성기의 직접 제어 변수 |
| Π₃ = n (입체 지수) | 이미 무차원 |
| Π₄ = Ea / (R·T_ref) | Arrhenius 무차원화 |

NN 은 Π 를 추정하고, 알려진 조건(AR, dose, T)으로 s₀ 등을 역산한다.

**(2) 남은 스케일 처리**
- 자릿수를 넘나드는 양은 **log10 변환 후 z-score**. prior 샘플링도 log-uniform.
- s₀ ∈ (0,1) 이지만 수십 배 범위 → **logit 또는 log** 공간.
- 출력도 log 공간에서 예측하고 물리 범위 강제(sigmoid/softplus) 후 역변환. 손실도 log 공간.
- 관측 y 는 이미 0..1 이라 그대로. log θ 를 두 번째 채널로 넣으면 깊은 쪽 작은 값의 정보가 산다.

## 4-c. 데이터 생성 — 비용과 체크포인팅

`src/generate_dataset.py`, `src/cyl_run.py`

**핵심 비용 절감 두 가지** (둘 다 실측으로 정한 것):

1. **dose 체크포인트 재사용.** MC 는 dose 방향으로 순차적이므로 한 번 돌리면서

   최악 비용이 사전에 결정되고, 바닥이 먼저 포화하면 조기 종료한다.

**실측 비용** (컨테이너 aarch64 단일 코어, numba):

| 항목 | 값 |

샘플마다 저장해 두므로, 학습 시 목표 측정노이즈까지의 **차분만** 추가하면 된다.

## 4-e. 왜 kMC 를 넣지 않는가 (그리고 왜 T 가 3점인가)

**결론: 하이브리드 kMC 미도입. 대신 학습 샘플 하나를 온도 3점 프로파일 세트로 만든다.**

근거는 식별성이다. T 의 유일한 효과가 s₀(T) = A·exp(−Ea/RT) 라면,
**단일 프로파일에서 T 는 정보를 전혀 추가하지 않는다.** s₀ 대신 (A, Ea) 를 출력하는 것은
순수한 재매개변수화이고, 같은 s₀ 를 주는 (A, Ea) 조합이 1-parameter family 로 무한히 많다.
kMC 를 넣는 이유로 제시됐던 "T 를 입력으로 쓰려면 필수"는 **틀린 근거였다** —
필요한 것은 rate 기반 이벤트가 아니라 **온도를 바꾼 관측 여러 개**다.

온도 3점(200/250/300 °C)이면 Ea 가 식별된다. 실측 확인 (`src/ident.py` 성격의 점검):

| Ea [kJ/mol] | T₁↔T₃ 프로파일 최대 차이 |
|---|---|
| 0 | 0.03 ~ 0.08 (= MC 잡음 바닥) |
| 15 | 0.10 ~ 0.22 |
| 30 | 0.20 ~ 0.52 |
| 60 | 0.40 ~ 0.87 |

즉 **Ea ≳ 15 kJ/mol 부터 노이즈 위로 올라온다.** 그 아래는 사후분포가 넓게 나오는 것이 정답이고,
그것이 MDN 을 쓰는 이유다. 덤으로 관측이 64 → 3×64 로 커져 "고차원 관측" 기준도 강해진다.

**부수 효과 — 명칭 정직성**: 이 시뮬레이터는 kMC 가 아니라
*feature-scale ballistic Monte Carlo (자유분자류 수송 + 자기제한 표면반응)* 이다.
발표·이력서 어디에도 kMC 라고 쓰지 않는다.

**언제 kMC 가 필요해지는가** (면접에서 물으면 이렇게 답한다): 전구체 열분해처럼
**입사 플럭스의 시계와 경쟁하는 rate 기반 표면 과정**이 있을 때. 그때는 Damköhler 수가 생기고
단일 프로파일에서도 T 축이 살아난다. 구현은 operator splitting(도즈를 부분 펄스로 쪼개고
사이사이 rate 과정 적용)으로 가능하지만, 이번 범위에서는 넣지 않는다.

## 5. 검증 계획

2. 최소제곱 baseline 정면 대결 (정확도 + 벽시계 시간, baseline 예산 명시)

## 6. Physics embedding — 아키텍처에 박는 자리

| 자리 | 내용 | 판단 |
|---|---|---|
| Arrhenius 헤드 | NN이 (s₀_ref, Ea) 출력 → s(T) 는 해석식 | **중심. 다중 T 세트로 성립, kMC 불필요** |
| 출력 파라미터화 | s∈(0,1) sigmoid, Ea softplus | 값싸고 확실 |

## 8. 정직성 원칙 (발표 시)

- 데이터는 **전부 시뮬레이터 합성**. 실험 검증 없음. 첫 슬라이드에 명시.
- **kMC 가 아니다.** ballistic MC + 자기제한 표면반응이라고 정확히 부른다.
- 축대칭 단면, 반쪽반응 하나, 사이클 반복 선형 가정, **표면확산 없음**, 성장에 따른 기하변화 없음.
- 재방출은 완전 확산(cosine) 고정 — 정반사 성분 미구현.
- n(입체), 재방출, 사이트밀도는 **온도 무관하다고 가정** — 실제로는 약한 T 의존이 있을 수 있음.
- 속도 미추적 (자유분자류에서 기하에는 불필요).
- step coverage 로부터 sticking coefficient 를 역추출하는 것 자체는 **기존 방법**.
  기여는 "상각(amortized) + 불확실성 정량화" 로 한정할 것.
- 학습·시험이 같은 시뮬레이터에서 나온다는 자기일관성 함정 → 검증 3·4 가 유일한 방어.

## 9. 표기

문헌 표준(Cremers–Puurunen–Dendooven 리뷰)을 따른다.
- **s** = sticking probability (충돌당 반응 확률), **s₀** = bare surface 초기값
- γ 는 플라즈마 쪽 표면반응·재결합 확률
- β 는 통용 표기가 아니므로 쓰지 말 것
