# ALD Conformality — Inverse Problem via Amortized Inference

고AR 구조의 **step coverage 프로파일**에서 표면반응 파라미터(sticking coefficient, 활성화에너지 등)를
불확실성과 함께 역추정하는 신경망. 측정마다 반복되는 시뮬레이션 최적화 루프를 학습된 추론기로 대체한다.

목적: ASM (Senior Engineer II, Product Intelligence) 면접용 포트폴리오.
부수 타깃: SK하이닉스 소자/TCAD, LG Display VDE (약함).

---

## 1. 문제

- ALD를 고AR trench/via에 하면 입구는 두껍고 바닥은 얇다 (step coverage).
- 알고 싶은 것: **sticking coefficient s₀, 그 활성화에너지 Ea, 입체 인자 n, 재방출 생존확률, 사이트 밀도**.
  이 값이 정해지면 *다른 AR 구조·다른 온도에 필요한 dose* 를 예측할 수 있다 = 공정 처방.
- 순방향 모델은 **시뮬레이터뿐**이다 (닫힌 해 없음): s(θ) 의존 → 비선형·비정상,
  재방출 각분포, 사이트 밀도 불균일이 들어가면 해석해가 사라진다.
- 따라서 기존 역추정 = 측정 1세트당 무도함수 최소제곱 → 시뮬 10³~10⁴회, 수 시간~수 일,
  확률적 목적함수(gradient 없음), 다봉, **불확실성 없음**.

## 2. 접근 — 확정 사양

```
파라미터 prior + 공정조건  →  MC 시뮬레이터  →  프로파일 + 측정열화  →  ~32만 예제
                                                                        ↓
                                          1D CNN + Mixture Density head 학습
                                                                        ↓
                                  측정 1장 → 순전파(0.13 ms) → 사후분포
                                                                        ↓
                                  단위 복원 · Arrhenius (해석식, 시뮬 불필요)
```

비용을 **측정 시점에서 학습 시점으로 이동**시키는 것이 핵심. 물리는 대체하지 않는다.

### 2-1. 추론 단위는 웨이퍼 한 장이다

측정 1건 = **하나의 구조 · 하나의 dose · 하나의 온도**에서 뜬 단면 프로파일 한 장.
온도 시리즈가 있으면 웨이퍼별 결과를 사후에 합친다 (§2-4).

### 2-2. 입출력 — 전부 무차원

| | 양 | 형태 | 근거 |
|---|---|---|---|
| **입력** | θ(z), 깊이 64칸 | 무차원 | 두께 / 평탄부 두께. 절대 단위 불필요 |
| | log₁₀ θ(z) | 무차원 | 깊은 쪽 작은 값 보존 |
| | 마스크 64칸 | 무차원 | "미측정"과 "맨 표면"을 구분 |
| | log AR = log(H/D) | 무차원 | Knudsen 영역 → 절대 치수 무의미 |
| **출력** | s₀ (그 웨이퍼 온도에서) | 무차원 | 충돌당 반응 확률 |
| | n | 무차원 | 입체 지수, s = s₀(1−θ)ⁿ |
| | p_reemit | 무차원 | 재방출 생존확률 |
| | **Π₂ = dose / 전체 사이트 수** | 무차원 | 사이트밀도의 무차원 표현 |

**네트워크가 보는 것도 내는 것도 전부 무차원이다.** 시뮬 단위계, `SPB_SCALE`, 기준 밀도 같은
임의 상수가 파이프라인 어디에도 남지 않는다.

### 2-3. 왜 dose 가 입력이 아닌가 / 왜 Π₂ 가 출력인가

시뮬레이터에서 dose 와 사이트 수를 **둘 다 λ배** 하면 θ 가 변하지 않는다 (반응 횟수 λ배,
한 번당 기여 1/λ). 즉 프로파일은 **오직 그 비에만** 의존한다:

```
θ(z) = F( AR , s₀ , n , p_reemit , Π₂ )
```

- **dose 는 입력에서 뺀다** — 프로파일이 이미 담고 있지 않은 정보를 추가하지 않는다.
- **Π₂ 는 입력이 될 수 없다** — 분모가 추정 대상(사이트밀도)이다. 순환이고, 실측으로
  사이트밀도가 오차 0.00 %로 역산되는 것을 확인했다 (§4-f, §4-g).
- **Π₂ 는 출력이어야 한다** — 프로파일을 결정하는 4개 미지수 중 하나다.

### 2-4. 단위는 밖에서 복원한다 (해석식, 시뮬 불필요)

**사이트 밀도**
```
n_s = N_dose / (4 · AR · Π₂)
```
`4·AR` 은 원통 기하에서 유도된 값이다 — 측벽 면적 / 입구 면적 = πDH / (πD²/4) = 4·AR.
`N_dose` 는 입구 단위면적당 입사 분자 수(= P·t/√(2πmkT), 공정이 정하는 값).
**구멍의 절대 지름 D 는 소거된다** — AR 만 있으면 된다.

**활성화에너지** — 온도 스플릿(웨이퍼 2장 이상)이 있을 때
```
ln s₀ = ln A − (Ea/k_B)(1/T)          k_B = 8.617×10⁻⁵ eV/K
```
웨이퍼별 s₀ 사후분포에서 표본을 뽑아 회귀를 반복하면 Ea 의 분포가 나온다.
**시뮬레이터 호출이 하나도 없다.** 무차원 형태 η = Ea/(k_B T̄) 를 함께 보고한다.
에너지 단위는 **eV** 로 통일 (DFT 연계 고려). kJ/mol 이 필요하면 ×96.485.

> Arrhenius 를 네트워크 밖에 두는 이유: 2-파라미터 선형회귀를 신경망에 시킬 이유가 없고,
> 밖에 두면 **임의의 온도·임의의 개수(2점·3점·5점)에 재학습 없이** 적용된다.
> 대가는 아키텍처 안의 물리가 얇아지는 것이다 (§6 참조).

### 2-5. 지위 표 — 코드보다 이게 먼저다

| 양 | 지위 |
|---|---|
| AR = H/D | 공정이 정함 |
| N_dose (절대 dose) | 공정이 정함. **네트워크에는 안 들어감**, 단위 복원에만 사용 |
| T | 공정이 정함. 웨이퍼당 하나. **네트워크 입력 아님** (라벨) |
| θ(z) 64칸 | 측정됨 |
| s₀, n, p_reemit, Π₂ | **추정** |
| n_s, Ea, η | **후처리로 유도** |
| Knudsen 영역 · cosine 재방출 · 표면확산 없음 · 성장 중 형상 불변 | 고정 가정 (§8) |

**순환 검사**: 입력 어느 것도 미지수를 포함하지 않는다. 통과.
(이전 두 번의 실패가 이 검사에서 걸렸다 — Π₂ 는 n_s 를 품고 있었고, dose 는 n_s 와 상관돼
있었다. 지금은 dose 자체가 입력에 없다.)

## 3. 시뮬레이터

**3D 축대칭 원통 via 의 탄도(자유분자류) 몬테카를로** (`src/cyl_mc.py`).
Knudsen(분자류) 영역 → **절대 치수 무관, AR = H/D 만 의미**. D=1 고정(R=0.5), H=AR.

> 2D slit 판(`src/trench_mc.py`)도 유지한다. 기하 비교 연구용이며, 두 기하의 투과확률이
> ln(AR)/AR 과 1/AR 로 갈리는 것을 보여주는 슬라이드 소재다. **학습 데이터는 원통으로만 만든다.**

입자 하나: 입구 원판 진입(cosine) → 직진 → 벽 충돌 → 확률 s(θ)=s₀(1−θ)ⁿ 로 반응(정지),
아니면 확산 재방출 → 반복. 반응하거나 입구로 탈출할 때까지.

**각분포**: 입구 진입도 재방출도 모두 안쪽 법선 기준 **cosine(Knudsen) 법칙**.
입구에서의 cosine 은 임의 가정이 아니라 평형 Maxwell 기체가 평면을 통과할 때의 정확한 각분포다.
재방출의 cosine 은 완전 열적응 + 무작위 탈리를 가정한 것으로, **여기가 모델링 선택 지점**이다
(실제 표면은 부분 정반사가 있을 수 있음).

**속도는 추적하지 않는다.** 자유분자류에서 벽 충돌 *순서* 는 속력과 무관하므로 기하 문제에는
방향만 있으면 충분하다. 속력이 필요해지는 건 (i) dose ↔ 시간 환산, (ii) rate 기반 표면 이벤트를
넣는 순간. 후자는 이번 범위에서 도입하지 않는다 (§4-e).

**표면 확산은 없다.** 반응한 종은 그 칸에 영구 고정된다. ALD 화학흡착종은 결합이 강해
공정 시간 척도에서 표면 확산이 무시할 만하다는 것이 통상적 근거이고, conformality 를 지배하는 것은
흡착종의 확산이 아니라 **전구체의 재방출** 이다 (이건 모델에 있음).

### θ 는 어떻게 계산되나 / '포화 두께' 의 정의

칸 i 에는 반응 가능한 표면기(site)가 `N_sites,i` 개 있다. 분자 하나가 그 칸에서 반응하면

    θ_i  ←  θ_i + weight / N_sites,i

즉 **θ = (그 칸에서 반응한 분자 수) / (그 칸의 사이트 수)** — 무차원, 0..1.

원통에서 칸 높이 = H/64, 벽 면적 = 2πR·H/64 = π·H/64 (D=1), 사이트 밀도 n_s →
`N_sites,i = n_s·π·H/64`. AR 을 바꾸면 칸 높이가 바뀌므로 **사이트 밀도를 고정하려면
N_sites ∝ AR 로 같이 키워야 한다** (생성기가 이렇게 한다).

**포화 두께** = 반쪽반응이 끝까지 갔을 때 그 사이클에 쌓이는 두께 = 평탄부 GPC. 그래서

    θ = 그 지점 두께 / 완전 포화 시 두께

이고, **측정에서는 TEM 단면의 두께를 웨이퍼 상부 평탄면(=완전 포화) 두께로 나누면 얻어진다.**
이 정규화가 측정 가능하다는 점이 중요하다 — 절대 단위를 알 필요가 없다.

공정조건이 들어가는 곳은 셋뿐:
- **AR** → 기하
- **dose** → 쏘는 입자 수. 무차원화하면 Π₂ = dose / 전체 사이트 수
- **T** → s₀ 의 Arrhenius 의존. 온도 3점 세트로 식별한다 (§4-e)

## 4. 지금까지 확인한 것 (실측)

### 4-1. 수송 검증 — 코드 게이트 (합격)

`src/cyl_mc.py` + `src/clausing_ref.py`, `figures/geometry_validation.png`

무반응(s₀=0) 투과확률을 **두 가지 독립적인 방법**으로 계산해 대조했다.

1. 탄도 MC (`cyl_mc.transmission`)
2. **Clausing 적분방정식의 결정론적 수치해** (`clausing_ref.py`) — MC 를 전혀 쓰지 않는다.
   원통 내벽의 링–링 교환 커널 k(u) = (R/π)∫₀^{2π} a²/D⁴ dψ 를 구적한 뒤 선형계를 푼다.
   자체 검증: k(0) = 1/(2R), ∫₀^∞ k du = 1/2 (둘 다 해석적으로 정확한 값과 일치).

| AR = H/D | MC (4×10⁶ 입자) | Clausing 수치해 | 차이 |
|---|---|---|---|
| 5 | 0.19117 ± 0.00020 | 0.19094 | +0.12 % |
| 10 | 0.10959 ± 0.00016 | 0.10932 | +0.25 % |
| 20 | 0.05942 ± 0.00012 | 0.05945 | −0.04 % |

AR 0.5~40 전 구간에서 **MC 통계오차 이내로 일치**. 짧은 관 극한에서 Clausing 의 고전값
(L/R=1 → 0.672, L/R=2 → 0.514)도 재현한다.
→ 2D slit 때의 "기울기 −0.65가 ln(AR)/AR 과 맞더라" 수준의 스케일링 확인이 아니라,
**절대값을 독립 기준과 대조하는 진짜 게이트**가 되었다. 이것이 원통을 택한 첫 번째 이유다.

2D slit 은 별개로 ln(AR)/AR 을, 원통은 4/(3·AR)(Knudsen 점근)을 따른다 — 같은 그림 (a) 패널.

### 4-2. 형상 붕괴 — Π₁ = AR·√s₀ (원통에서 더 깨끗해짐)

낮은 dose(선형 영역)에서 θ(z)/θ(0) 형상 비교:

| 묶음 | (AR, s₀) | 바닥/입구 비 | 판정 |
|---|---|---|---|
| AR·s₀ = 0.4 | (10, .04) / (20, .02) / (40, .01) | 0.056 / 0.023 / 0.004 | **붕괴 안 함** |
| **AR·√s₀ = 2.0** | (10, .04) / (20, .01) / (40, .0025) | 0.056 / 0.065 / 0.060 | **붕괴함 (±8 %)** |

2D slit 에서는 같은 시험이 0.407/0.421/0.448 (±10 % 드리프트)이었다. 원통이 더 깨끗한 것은
예상과 맞는다 — 2D 의 ln(AR) 보정항이 없기 때문이다.

**Π₁ 이 왜 √s₀ 인가.** 깊이 방향 1D 반응–확산으로 보면 D_K d²C/dz² = k C 이고,
Knudsen 확산계수 D_K ∝ W·v̄, 단위 길이당 소모율 k ∝ s₀·v̄/W.
침투 깊이 λ = √(D_K/k) ∝ **W/√s₀**. 바닥까지 닿으려면 **AR·√s₀ ≲ O(1)**.

### 4-3. 폐기된 주장

**`dose ∝ AR²` 를 코드 게이트로 쓰지 말 것.** Gordon 의 AR² 는 *큰 a · 완전 포화 기준 ·
수송율속* 점근이지 보편 법칙이 아니다. 2D slit 실측 지수: s₀=0.05→0.39, 0.2→0.81, 0.6→1.21.
게이트는 4-1 을 쓴다. (원통에서 완전 포화 기준으로 재측정하면 2 에 접근하는지는 **미확인 — 다음 할 일**.)

## 4-f. Π₂ 를 알려진 조건으로 주면 사이트밀도가 죽는다 (실측)

**NN 과 baseline 의 조건 입력은 절대 dose 여야 한다.** Π₂ = dose / (전체 사이트 수) 는
분모에 우리가 추정하려는 사이트밀도가 들어 있어 순환이다. 이걸 "알려진 값"으로 주면
사이트밀도가 **정확히** 식별 불가능해진다.

측정 (`AR=15`, 나머지 고정, 프로파일 최대 변화):

| n_sites 변경 | Π₂ 고정 | 절대 dose 고정 |
|---|---|---|
| 4 → 8 (2배) | **0.0000** | 0.2758 |
| 4 → 2 (절반) | 0.0307 (MC 이산화 수준) | 0.2800 |

측정노이즈가 0.030 이니, Π₂ 고정에서는 신호가 아예 없고 절대 dose 고정에서는 노이즈의 9배다.

**데이터셋은 재생성할 필요 없다.** 저장된 `c[:,1]=pi2` 와 `q[:,0]=sites_per_bin` 에서
절대 분자 수 = `pi2 * sites_per_bin * NBIN` 로 복원된다. 학습 코드가 이걸 조건으로 쓴다.
다만 dose 와 n_sites 는 prior 에서 상관되어 있다 (dose = Π₂ · n_s · const, Π₂ 는 log-uniform).
이건 버그가 아니라 prior 구조이므로 발표 시 명시할 것.

## 4-g. 데이터셋이 정답을 흘리고 있었다 (실측 → 수정)

첫 학습이 **너무 잘 나왔다**. 시험 shard 30개에서 s₀ 중앙오차 6.5 %, 사이트밀도 4.4 %,
보정 곡선은 거의 완벽. 같은 벤치마크에서 최소제곱 baseline 은 s₀ 133.9 %, 사이트밀도 39.7 %.
20배 차이는 의심할 근거다. 파보니 누설이었다.

**메커니즘**: 생성기가 dose 를 `dose = Π₂ · n_sites · π·AR·SPB_SCALE` 로 만드는데
Π₂ 가 **고정된 6개 값**이었다. 조건으로 주는 dose 를 그 6개로 나눠보면 사이트밀도 후보가 나온다.

**수정**: draw 마다 체크포인트 격자에 log 오프셋 `U(±0.3625)` 를 곱한다 (`PI2_JITTER`).
격자 간격이 log 0.725 이므로 오프셋이 격자를 **틈 없이 메워** Π₂ 가 전 구간에서 연속·log-균일이 된다.
→ dose 와 AR 을 알아도 n_sites 는 prior 이상으로 좁혀지지 않는다.
이전 데이터셋은 `results/dataset_v1_leaky` 로 보관. 재생성본으로 다시 학습했다.

### 게이트 — `src/leak_test.py` (600 shard 재생성본, 통과)

네 가지를 재고, 각각을 **지터를 해석적으로 제거한 열**과 나란히 찍는다 (Π₂ 를 격자로 되돌리고
dose 재계산). 그 열이 옛 누설을 재현하지 못하면 게이트에 이빨이 없다는 뜻이므로, 음성 대조가
검사의 일부다.

| | 지터 제거 (v1) | 실제 데이터셋 |
|---|---|---|
| 격자로부터의 offset 중앙값 (반칸 단위) | 0 | **0.506** (균일이면 0.50) |
| 6개 후보 중 정답을 골랐을 때 n_sites 재현 오차 | **0.00 %** | **19.50 %** |
| (AR, dose) 만으로 남는 log n_sites prior 비율 | — | 중앙값 **1.000**, 74 % 는 손실 0 |
| 조건만 kNN 의 n_sites 오차 (prior 중앙값 null 26.3 %) | **1.85 %** | **23.29 %** |
| 조건만 kNN 의 나머지 3개 / null 비 | — | 1.02 ~ 1.24 |

마지막 두 줄이 핵심이다. 지터를 빼면 n_sites 가 조건만으로 1.85 % 까지 복원되고 (누설),
지터가 있으면 23.29 % 로 prior 수준에 머문다. 네트워크가 실제로 보는 조건은 **log AR 하나뿐**이고,
그것만으로는 네 목표 어느 것도 prior 를 이기지 못한다 (비 ≥ 1.02).

> `kNN on AR, dose` 만 Π₂ 를 23 % 로 맞춘다 (null 80 %). dose 와 AR 을 알면 곱 Π₂·n_sites 가
> 정확히 고정되고, n_sites prior 가 3배 폭으로 좁아서 Π₂ 가 부분적으로 읽히는 것이다.
> **네트워크는 dose 를 보지 않으므로 도달 불가능한 경로**이고, prior 구조 자체는 §4-f 에 명시돼 있다.

> **교훈**: 결과가 기대보다 좋으면 먼저 누설을 의심하라. 이 프로젝트에서 두 번 다 그랬다 —
> §4-f 는 오차 방향이 일관돼서, §4-g 는 정확도가 지나쳐서 잡혔다.

## 4-h. 재방출 prior 가 ALD window 밖까지 덮고 있다 (실측)

고AR 전이 시험을 짜다가 발견. AR 50 에서 바닥이 안 덮이는 케이스가 절반이었고, 처음엔
"AR 이 높으면 원래 그렇다"로 넘어갈 뻔했다. 실제로 무엇이 가르는지 재보니 AR 이 아니었다.

| case | s₀ | reemit | AR 50, Π₂ = 600 에서 바닥 |
|---|---|---|---|
| 6 | 0.259 | 0.990 | 1.000 |
| 0 | 0.249 | **0.907** | 0.892 |
| 1 | 0.024 | 0.964 | 0.360 |
| 3 | 0.0055 | 0.938 | **0.163** |

case 0 은 재방출 생존이 가장 낮은데도 바닥을 덮고, case 3 은 더 높은데 못 덮는다.
가르는 것은 **바운스당 소실 (1 − p_reemit) 대 s₀ 의 경쟁**이다. 소실이 s₀ 보다 크면
분자가 어디서든 반응하기 전에 죽는다.

prior 에서 그 비율:

```
P(loss > s₀)      = 44.4 %
P(loss > 3 · s₀)  = 22.8 %
median loss/s₀    = 0.77
```

**학습셋의 44 % 가 "반응보다 소실이 잦은" 영역이다.** 이상적 self-limiting ALD 에는 그런
소실 채널이 없다 — 반응하지 않은 전구체는 desorb 해도 구멍 안에 남아 랜덤워크를 계속하고,
모델에서 구멍 밖으로 나가는 탈출은 이미 따로 처리된다. 바운스당 10 % 소실이라면 그것은
열분해나 비가역 비반응 흡착이고, 그 지점은 **이미 ALD window 밖**이다.
`reemit` prior 를 `U(0.90, 1.0)` 로 잡은 것이 너무 넓었다.

**대응 (재생성 없이)**: 학습은 넓은 prior 그대로 둔다 (보수적인 방향이다). 대신 **전이 시험의
케이스를 `s₀ > 3·(1 − p_reemit)` 인 ALD 다운 영역에서만** 뽑고, 그 필터를 결과와 함께 찍는다
(`src/transfer_ar.py --min-ratio`). 목표치를 몰래 낮추는 것과 다르다 — 목표는 그대로 두고,
질문이 성립하는 영역을 명시하는 것이다.

시간이 남으면 prior 를 `U(0.98, 1.0)` 등으로 좁혀 재생성·재학습하는 것이 근본 해결이다.

## 4-b. 무차원화와 정규화 (NN 학습 전 필수)

**(1) 무차원군으로 묶기**

| 무차원군 | 의미 | 현재 파이프라인에서의 자리 |
|---|---|---|
| **Π₁ = AR · √s₀** | 수송 대 반응 경쟁 — 프로파일 *모양* 을 지배 (§4-2 에서 실측 확인) | AR 이 입력이므로 s₀ 와 전단사. **출력을 s₀ 로 둘지 Π₁ 로 둘지는 소거 실험으로 잰다** — §6, `src/ablation_param.py` |
| Π₂ = dose / (전체 사이트 수) | 사이트당 입사 분자 수 | **출력**. 입력으로 주면 사이트밀도가 죽는다 — §4-f, §4-g |
| Π₃ = n (입체 지수) | 이미 무차원 | **출력** (`n_steric`) |
| Π₄ = Ea / (R·T_ref) | Arrhenius 무차원화 | **네트워크 밖**. 웨이퍼별 s₀ 사후분포로 닫힌 형태 회귀 — §2-4 |

> **이 표는 초기 설계안이었고, §2 가 정본이다.** 세션 2 에서 관측 단위를 재정의하면서
> Π₂ 는 입력→출력으로 옮겼고(§4-f·§4-g), Π₄ 는 네트워크 밖으로 뺐다(§2-4). 그때
> **Π₁ 도 조용히 s₀ 로 바뀌었는데 근거가 기록되지 않았다** — 세션 3 에서 사용자가 발견.
> AR 이 조건으로 들어가 있어 표현력은 사실상 같고, 실제 차이는 손실의 z-정규화가
> "프로파일이 결정하는 양" 기준이 되느냐뿐이다. 추측 대신 재기로 했다 (§6).
>
> 아래 두 줄도 옛 설계의 잔재였다: **dose 와 T 는 네트워크 입력이 아니다** (§2-3, §2-5).
> 알려진 조건 중 네트워크에 들어가는 것은 **AR 하나뿐**이고, dose 와 T 는
> 사후 단위 복원(§2-4)에서만 쓰인다.

**(2) 남은 스케일 처리**
- 자릿수를 넘나드는 양은 **log10 변환 후 z-score**. prior 샘플링도 log-uniform.
- s₀ ∈ (0,1) 이지만 수십 배 범위 → **logit 또는 log** 공간.
- 출력도 log 공간에서 예측하고 물리 범위 강제(sigmoid/softplus) 후 역변환. 손실도 log 공간.
- 관측 y 는 이미 0..1 이라 그대로. log θ 를 두 번째 채널로 넣으면 깊은 쪽 작은 값의 정보가 산다.

## 4-c. 데이터 생성 — 비용과 체크포인팅

`src/generate_dataset.py`, `src/cyl_run.py`

**핵심 비용 절감 두 가지** (둘 다 실측으로 정한 것):

1. **dose 체크포인트 재사용.** MC 는 dose 방향으로 순차적이므로 한 번 돌리면서
   Π₂ = 0.8 … 30 의 6개 지점에서 스냅샷을 뜬다. 스냅샷 하나하나가 유효한 학습 샘플이다.
   → 실행 1회당 샘플 6개.
2. **Π₂ 기반 dose 상한.** "포화까지 돌린다"가 아니라 사이트당 dose 를 미리 정한다.
   최악 비용이 사전에 결정되고, 바닥이 먼저 포화하면 조기 종료한다.

**실측 비용.** 머신마다 크게 다르니 반드시 자기 머신에서 재라.

| 머신 | 학습 샘플 1개당 | 10,800 샘플 |
|---|---|---|
| 개발 컨테이너 (aarch64, 1코어) | 3.7 s · 코어 | 11 코어·시간 |
| **dhl-desktop (x86, 6코어)** | **약 1.4 s · 코어** | **약 4 코어·시간 = 50분** |

> **경고 — 초기 추정이 10배 틀렸던 이력.** 컨테이너에서 잰 "실행 1회 중앙값 14 s" 를 그대로
> 샘플당 15 s 로 환산해 "45 코어·시간"이라고 적었었다. 같은 세션의 smoke test 는 이미
> 3.7 s/샘플이라고 말하고 있었는데 대조하지 않았다. **아키텍처가 다른 머신의 수치를 옮기지 말 것,
> 그리고 자기 측정치끼리 모순되면 반드시 맞춰볼 것.**

MC 계수 잡음 σ_θ = √(weight / sites_per_bin). weight 상한 때문에 **2.9 % 가 바닥**이고,
sites_per_bin 이 작은 저AR·저사이트밀도 조합에서 최대 4 % 까지 올라간다.
샘플마다 저장해 두므로, 학습 시 목표 측정노이즈까지의 **차분만** 추가하면 된다.

**체크포인팅**
- `results/dataset/shard_XXXX.npz`, 파일이 있으면 건너뜀 → **재실행이 곧 이어하기**
- 원자적 쓰기(`.tmp` → `os.replace`) → 중단되어도 반쪽 shard 가 남지 않음
- `seed = shard_id*100003 + i*3` — 재현성보다 **워커 간 RNG 충돌 방지**가 이유
- shard 는 원하는 만큼 추가할 수 있다. `--shards 60-599` 처럼 범위를 주면 되고,
  **shard id 가 파라미터 RNG seed 를 결정하므로 새 shard 는 중복 없이 새 샘플만 만든다.**
  기본 60 shard = 10,800 샘플, 600 shard = 108,000 샘플 (디스크 약 94 MB)

> **⚠ 학습/검증 분할은 반드시 shard(또는 draw) 단위로 하라.**
> 한 draw 에서 나온 체크포인트 6개는 **파라미터가 전부 동일하다.** 예제 단위로 무작위 분할하면
> 같은 정답이 train 과 test 양쪽에 들어가 성능이 부풀려진다. 예: train 0–539 / val 540–569 /
> test 570–599.
- `multiprocessing.Pool.imap_unordered`. 실행은 `nohup python -u ... > gen.log 2>&1 &` 로 충분하다
  (재실행이 곧 이어하기라 세션 유지가 필요 없다. `-u` 없으면 로그가 버퍼링된다)
- `@njit(cache=True)` 라 재시작 시 재컴파일 없음

## 4-e. 왜 kMC 를 넣지 않는가 (그리고 왜 T 가 3점인가)

**결론: 하이브리드 kMC 미도입. 대신 학습 샘플 하나를 온도 3점 프로파일 세트로 만든다.**

근거는 식별성이다. T 의 유일한 효과가 s₀(T) = A·exp(−Ea/RT) 라면,
**단일 프로파일에서 T 는 정보를 전혀 추가하지 않는다.** s₀ 대신 (A, Ea) 를 출력하는 것은
순수한 재매개변수화이고, 같은 s₀ 를 주는 (A, Ea) 조합이 1-parameter family 로 무한히 많다.
kMC 를 넣는 이유로 제시됐던 "T 를 입력으로 쓰려면 필수"는 **틀린 근거였다** —
필요한 것은 rate 기반 이벤트가 아니라 **온도를 바꾼 관측 여러 개**다.

온도 3점(200/250/300 °C)이면 Ea 가 식별된다. 실측 확인 (`src/ident.py` 성격의 점검):

| Ea [kJ/mol] | T₁↔T₃ 프로파일 최대 차이 |
|---|---|
| 0 | 0.03 ~ 0.08 (= MC 잡음 바닥) |
| 15 | 0.10 ~ 0.22 |
| 30 | 0.20 ~ 0.52 |
| 60 | 0.40 ~ 0.87 |

즉 **Ea ≳ 15 kJ/mol 부터 노이즈 위로 올라온다.** 그 아래는 사후분포가 넓게 나오는 것이 정답이고,
그것이 MDN 을 쓰는 이유다. 덤으로 관측이 64 → 3×64 로 커져 "고차원 관측" 기준도 강해진다.

**부수 효과 — 명칭 정직성**: 이 시뮬레이터는 kMC 가 아니라
*feature-scale ballistic Monte Carlo (자유분자류 수송 + 자기제한 표면반응)* 이다.
발표·이력서 어디에도 kMC 라고 쓰지 않는다.

**언제 kMC 가 필요해지는가** (면접에서 물으면 이렇게 답한다): 전구체 열분해처럼
**입사 플럭스의 시계와 경쟁하는 rate 기반 표면 과정**이 있을 때. 그때는 Damköhler 수가 생기고
단일 프로파일에서도 T 축이 살아난다. 구현은 operator splitting(도즈를 부분 펄스로 쪼개고
사이사이 rate 과정 적용)으로 가능하지만, 이번 범위에서는 넣지 않는다.

| **입출력을 무차원군으로 정의** | 네트워크가 보고 내는 것이 전부 무차원. 단위 복원은 밖에서 해석식 | **중심.** 시뮬 단위계 의존이 0 이 된다 (§2) |
| Arrhenius 를 밖으로 | 2-파라미터 선형회귀를 신경망에 안 시킴 | 임의 온도·개수에 재학습 없이 적용 |
| 출력 파라미터화 | s₀·Π₂ 는 log 공간, 범위 강제 | 값싸고 확실 |
| **출력을 Π₁ 로 둘지 s₀ 로 둘지** | AR 이 조건이라 전단사. 차이는 손실 정규화가 형상 붕괴 변수 기준이 되느냐 | **소거 실험으로 측정** (`src/ablation_param.py`). 결과가 나오면 여기에 숫자를 적는다 |
| Δ-learning | Gordon 근사로 초벌 추정 → NN은 잔차 | 미구현. 시간 남으면 |

솔직한 평가: **아키텍처 안에 박힌 물리는 얇다.** Arrhenius 를 밖으로 뺐으니 남은 것은
출력 범위 제약과 무차원 입출력 정의뿐이고, 2019년 프로젝트(비음수 제약을 출력층에)보다 약하다.
대신 **"무엇을 신경망에 시키고 무엇을 해석식으로 두는가"의 판단**이 명시적으로 드러나는 설계다.

## 8. 정직성 원칙 (발표 시)

- 데이터는 **전부 시뮬레이터 합성**. 실험 검증 없음. 첫 슬라이드에 명시.
- **ALD window 를 예측한다고 말하지 말 것.** window 상한은 전구체 열분해(CVD 화)인데
  §4-e 에서 열분해를 뺐고 하한(불완전 반응·응축)도 모델에 없다. 말할 수 있는 건
  **window 안에서 온도가 conformality 와 필요 dose 를 어떻게 바꾸는가** 까지다.
- prior 밖 조건(AR<10, AR>50, s₀<0.005 등)에서는 결과가 무의미하다.
- **재방출 prior 가 ALD window 밖까지 덮는다** (§4-h). 학습셋의 44 % 가 반응보다 소실이 잦은
  영역이다. 전이 시험은 ALD 영역 필터를 건 draw 에서만 돌렸고, 그 사실을 슬라이드에 쓴다.
- 전이 시험이 요구하는 Π₂ (46~138)는 **학습 prior(0.8~43) 밖**이다. 이건 의도된 것이다 —
  추론은 prior 안에서 하고, 그 파라미터로 시뮬레이터를 prior 밖까지 굴리는 것이 요점.
- **kMC 가 아니다.** ballistic MC + 자기제한 표면반응이라고 정확히 부른다.
- 축대칭 단면, 반쪽반응 하나, 사이클 반복 선형 가정, **표면확산 없음**, 성장에 따른 기하변화 없음.
- 재방출은 완전 확산(cosine) 고정 — 정반사 성분 미구현.
- n(입체), 재방출, 사이트밀도는 **온도 무관하다고 가정** — 실제로는 약한 T 의존이 있을 수 있음.
- 속도 미추적 (자유분자류에서 기하에는 불필요).
- step coverage 로부터 sticking coefficient 를 역추출하는 것 자체는 **기존 방법**.
  기여는 "상각(amortized) + 불확실성 정량화" 로 한정할 것.
- 학습·시험이 같은 시뮬레이터에서 나온다는 자기일관성 함정 → 검증 3·4 가 유일한 방어.

## 9. 표기

문헌 표준(Cremers–Puurunen–Dendooven 리뷰)을 따른다.
- **s** = sticking probability (충돌당 반응 확률), **s₀** = bare surface 초기값
- γ 는 플라즈마 쪽 표면반응·재결합 확률
- β 는 통용 표기가 아니므로 쓰지 말 것
